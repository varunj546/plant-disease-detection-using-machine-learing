# 🌱 Plant Disease Detection Using Machine Learning

## 📌 Project Overview

Plant diseases can affect crop quality and production. Early detection of plant diseases can help farmers take appropriate action.

This project uses Machine Learning and Deep Learning to identify plant diseases from leaf images.

A Convolutional Neural Network (CNN) is trained to classify plant leaf images into different disease categories.

## 🎯 Objective

The main objective of this project is to develop a model that can:

- Identify plant diseases from leaf images
- Classify healthy and diseased leaves
- Help in early plant disease detection

## 📊 Dataset

This project uses the PlantVillage dataset.

The dataset contains approximately 54,303 leaf images divided into 38 categories.

Dataset:
https://github.com/spMohanty/PlantVillage-Dataset

## 🤖 Machine Learning Model

The project uses:

- Convolutional Neural Network (CNN)
- TensorFlow
- Keras
